# Deep Learning Intro (From Scratch)

This folder contains a minimal Deep Learning introduction implemented manually.

## Rules followed

- No high-level DL frameworks (`torch`, `tensorflow`, `keras`) are used.
- Core math is implemented with basic `numpy` operations (`dot`, sums, element-wise ops).
- Forward pass, backward pass, and gradient descent updates are written by hand.

## File

- `intro_dl_from_scratch.ipynb`:
  - `LinearLayer` (manual dense layer)
  - `ReLU` activation
  - `mse_loss` with manual gradient
  - Full training loop for a small regression task

## Run

Open the notebook and run cells from top to bottom:

- `lessons/deep_learning_intro_from_scratch/intro_dl_from_scratch.ipynb`
